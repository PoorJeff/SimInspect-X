# Executive Summary

## Project type
Graduate-application flagship robotics project.

## System
Autonomous mobile robot in a simulated industrial plant.

## Inspection target
Analog gauges attached to industrial assets.

## Why gauges
They create a closed, measurable chain:
- navigation;
- viewpoint selection;
- visual observability;
- precise alignment;
- machine vision;
- confidence;
- re-inspection;
- ground-truth evaluation.

## Main baseline vs proposed comparison

### Baseline
Fixed inspection waypoint per asset.

### Proposed
Multiple candidate viewpoints + perception-aware scoring + confidence-triggered re-inspection.

## Core output
A table showing whether the proposed method improves:
- successful readable inspections;
- gauge-reading error;
- mission efficiency;
- robustness under occlusion / pose error / image degradation.

## Control output
PID vs MPC for precision approach.
