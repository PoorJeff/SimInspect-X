# NTU-Oriented Admissions Alignment

This matrix is based on the current 2026 NTU curriculum pages used when the blueprint was created.

## Robotics & Intelligent Systems

| Curriculum theme | SimInspect-X evidence |
|---|---|
| Advanced Robotics & Autonomous Systems | full perception-cognition-action-system pipeline |
| Sensors and Data Fusion | wheel odometry + IMU EKF; LiDAR-based mapping/localisation |
| Autonomous Mobile Robot | SLAM, localisation, planning, navigation, recovery |
| Vision | gauge detection, rectification, reading, confidence |
| Advanced Linear Systems and Control | precision motion/control study |
| Metaverse and Digital Twin | simulation-first plant/asset testbed, carefully scoped wording |
| Manufacturing Control and Automation | industrial inspection mission and asset-level workflow |
| Robotics Projects | end-to-end reproducible project + report |

## Computer Control & Automation

| Curriculum theme | SimInspect-X evidence |
|---|---|
| Computer Control Systems | digital feedback controller, sampling, implementation |
| Systems Analysis / optimisation | viewpoint scoring, optional mission ordering, quantitative models |
| Robotics & Intelligent Sensors | AMR, sensing, motion planning, integration |
| Machine Vision | gauge reading |
| Multivariable Control / MPC | constrained MPC precision approach |
| ML / optimisation electives | optional perception extensions and optimisation |

## Strategic principle

The project should not try to prove "I know ROS".
It should prove:

> "I can formulate, implement and evaluate an autonomous system where perception, planning and control interact."
