# Scope Tiers

## Tier A — GOLD CORE (must finish)
- robot + sensors;
- EKF / mapping / localisation;
- Nav2;
- 5–8 gauge assets;
- gauge reader;
- fixed waypoint baseline;
- candidate viewpoints;
- quality-aware selection;
- confidence-triggered alternative viewpoint;
- mission report;
- basic fault scenarios;
- benchmark plots.

If time is limited, finish this before anything else.

## Tier B — RESEARCH EDGE
- PID vs MPC precision approach;
- richer viewpoint quality model;
- stronger occlusion tests;
- ablation studies;
- route-order heuristic/optimisation;
- more rigorous confidence calibration.

## Tier C — SHOWCASE STRETCH
Only after Tier A+B are accepted:
- anomaly detection;
- optional natural-language mission parser;
- web dashboard;
- semantic asset graph;
- multi-robot;
- learned viewpoint policy.

Never sacrifice Tier A completeness for Tier C novelty.
